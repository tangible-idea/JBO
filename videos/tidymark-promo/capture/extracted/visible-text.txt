[p] In the toolbar
[h2] One click and it picks the folder.
[p] Open the popup on any page. Tidymark reads the title, the address and the page description, then ranks your existing folders by how well they fit.
[b] Your three best folders, with a confidence score
[span] Tap one to save. The button tells you exactly where the bookmark will land.
[b] It won't force a bad fit
[span] When nothing scores high enough, it suggests a new folder, named after the site and placed next to the closest match.
[b] No duplicates
[span] Already saved that address? Tidymark moves the existing bookmark instead of making a second one.
[b] Auto-save if you want it
[span] Off by default. Turn it on and pages save themselves only when confidence clears your threshold.

[h2] What leaves your browser.
[p] Last updated
[p] September 25, 2026
[a] Read the full privacy policy →
[dt] Where classification happens
[dd] Tidymark sends pages to the Tidymark server for classification. It runs on Google Cloud Run in Seoul, South Korea. You can instead run your own server and point the extension at it in Settings; Chrome asks for your permission before the extension can reach a new address.
[dt] What is sent
[dd] For each bookmark or page being classified: its title, address, and page description (or text you have selected on the page). For folder matching, the names of your folders. To read descriptions and check links, the server visits the bookmarked addresses.
[dt] The interest report
[dd] When you run the interest report or project grouping, bookmark titles, addresses and descriptions are sent from the server to a large language model through the Poe API. Classification uses the TypeSafe API. Nothing goes to these services unless you start that feature.
[dt] Browsing history
[dd] Optional, and only asked for when you turn it on in the sort-by-usage mode. History is read inside your browser to decide how recently you used a page. It is never sent to any server.
[dt] What is stored
[dd] Your settings live in Chrome's extension storage. The Tidymark server writes nothing to disk: it keeps page titles and descriptions only in a short-lived memory cache so it doesn't fetch the same page twice, and forgets them when it restarts. Nothing is tied to you, because there are no accounts.
[dt] What we don't do
[dd] No accounts, no ads, no analytics, no selling or sharing of your data. Data is used only to organize your bookmarks.
