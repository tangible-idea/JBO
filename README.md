# JEV 북마크 분류기

현재 Chrome 탭의 제목, URL, 설명을 TypeSafe JEV로 분류해 기존 북마크 폴더를 추천하는 Manifest V3 확장프로그램입니다. API 키가 노출되지 않도록 JEV 호출은 로컬 Node 백엔드에서만 수행합니다.

## 한 번에 실행

Node.js 20 이상이 필요합니다.

```bash
make setup
```

처음 실행했다면 `.env`의 `TYPESAFE_API_KEY`에 실제 키를 입력합니다. 이후에는 아래 명령 하나가 의존성 확인, 테스트, 문법 검사, API 키 확인을 거쳐 서버를 실행합니다.

```bash
make
```

다른 터미널에서 `make chrome`을 실행하면 Chrome 확장 관리 화면과 로드할 `extension` 폴더가 함께 열립니다. **개발자 모드 → 압축해제된 확장 프로그램을 로드합니다**를 한 번 선택하세요. Chrome 보안상 이 최초 설치 클릭은 자동화할 수 없습니다. 이후에는 툴바의 확장 아이콘을 누르면 현재 페이지를 분류할 수 있습니다.

사용 가능한 자동화 명령은 `make help`에서 확인할 수 있습니다.

`.env`를 바꾼 뒤 이미 서버가 실행 중이라면 `make restart`로 새 환경을 반영합니다. `make status`는 현재 서버에 API 키가 반영됐는지 확인합니다.

기본 백엔드 주소는 `http://127.0.0.1:8787`입니다. 배포된 HTTPS 백엔드를 사용할 때는 확장의 설정 화면에서 주소를 바꾸고 접근 권한을 승인하세요.

## 사용 흐름

### 팝업 — 지금 보는 페이지 저장

- 팝업을 열면 JEV가 바로 어울리는 기존 폴더 상위 3곳을 추천합니다. 설정에서 끌 수 있습니다.
- **기존 폴더에 넣기** 탭: 추천을 누르거나 트리에서 직접 골라 저장합니다. 버튼에 저장할 폴더 이름이 표시됩니다.
- **새 폴더 만들기** 탭: 확신도가 기준 이하이거나 맞는 폴더가 없으면 새 폴더를 제안합니다. 이름은 사이트에서 추정하고, 위치는 가장 가까운 추천 폴더 옆으로 잡습니다.
- 이미 북마크된 URL이면 중복 생성 대신 기존 북마크를 선택한 폴더로 옮깁니다.
- 자동 저장은 기본으로 꺼져 있습니다. 켜면 확신도가 기준을 넘을 때만 자동 저장합니다.

### 정리 스튜디오 — 기존 북마크 전체 정리

팝업의 **전체 정리** 또는 확장 설정 화면에서 엽니다. 두 가지 방식이 있습니다.

- **A. 새 폴더 만들어서 정리**: 카테고리를 칩으로 정하면 `정리 폴더 / 카테고리` 구조를 새로 만들어 북마크를 나눠 담습니다.
- **B. 기존 폴더에 쏙쏙 집어넣기**: 지금 폴더 구조는 그대로 두고, 체크한 대상 폴더(최대 100개) 중 가장 잘 맞는 곳으로 북마크를 옮깁니다. 이미 제자리에 있는 북마크는 건너뜁니다.

공통으로 전체 북마크 또는 특정 폴더 안만 정리할 수 있습니다. 서버는 각 북마크의 페이지 제목과 메타 설명·키워드·사이트 이름을 읽어 JEV로 분류합니다. 결과는 목적지 폴더별로 묶인 이동 예정표로 보여 줍니다. 항목마다 목적지를 바꿀 수 있고, 확신도가 기준 이하인 항목은 ‘검토 필요’로 표시되어 기본 선택에서 빠집니다. 적용 전에는 아무것도 바뀌지 않으며, 마지막 정리는 되돌릴 수 있습니다.

### 관심사 분석 — Poe LLM으로 폴더 구조 추천

정리 스튜디오의 **관심사 분석** 탭에서 실행합니다. `.env`에 `POE_API_KEY`가 필요하고, 모델은 `POE_MODEL`로 바꿀 수 있습니다(기본 `Claude-Sonnet-4.6`).

1. 모든 북마크의 페이지 제목과 메타정보(설명·키워드·사이트 이름)를 읽습니다.
2. 전체를 JSON 한 파일로 `data/snapshots/bookmarks-<시각>.json`(최신본은 `data/bookmarks-latest.json`)에 저장합니다. LLM 호출이 실패해도 이 파일은 남습니다.
3. Poe의 OpenAI 호환 API로 LLM에 보내 관심 분야(비중, 근거)와 새 폴더 구조(상위/하위 폴더)를 받습니다. 결과는 `data/profile-latest.json`에 저장됩니다. 북마크가 많으면 설명을 줄이거나 균등 추출해 컨텍스트에 맞춥니다.
4. **이 구조로 정리하기**를 누르면 추천 구조가 A 방식(새 폴더 만들어서 정리)의 카테고리로 들어갑니다. `개발 / 프론트엔드` 같은 하위 폴더도 그대로 만들어집니다.

## 검증

```bash
make verify
make doctor
```

`GET /health`는 서버와 API 키 설정 상태를, `POST /api/classify`는 단일 페이지 분류를, `POST /api/classify-batch`는 카테고리(`categories`) 또는 기존 폴더(`folders`) 기준의 일괄 분류를, `POST /api/metadata`와 `POST /api/profile`은 관심사 분석을 제공합니다.
